Before you start: how to edit a file in Hostinger

Several steps ask you to change one small line in a file. You always do it the same way:

  1. Log in at hpanel.hostinger.com.
  2. Click Websites in the left menu, then Dashboard (or Manage) next to frogsdream.com.
  3. In the left menu, open Files → File Manager. A new tab opens.
  4. Double-click the public_html folder, then the folders down to the file (for example assets, then js, then config.js).
  5. Double-click the file (or right-click it and choose Edit). A text editor opens.
  6. Change only the text between the quote marks "...". Do not delete the quote marks, commas or other symbols.
  7. Click Save (the disk icon, top right). Then open the website and press Ctrl+F5 to see the change.

The only settings file is public_html/assets/js/config.js. It looks like this:

window.FD_CONFIG = {
  ADSENSE_CLIENT: "",          // AdSense ID, step 7
  AD_SLOT_IN_ARTICLE: "",      // optional, leave empty
  PACK_URL: "https://buy.stripe.com/6oU5kD4iYeTr5eJ4oN7kc05", // already set, step 6
  PACK_PRICE: "$7",
  TIP_URL: "",                 // optional Ko-fi link
  CONTACT_EMAIL: "hello@frogsdream.com"
};

An empty value "" switches that feature off. While ADSENSE_CLIENT is empty, no ads load. Your Stripe payment link is already built into the zip, so the Buy button works from the first upload and stays after every new upload. The only value left for you to paste later is ADSENSE_CLIENT (step 7).

Tip: before you edit a file, right-click it and choose Download. Then you have a backup copy if something goes wrong.
Step 1 · about 10 minutes

Upload the website

a) Check that SSL (https) is on

  1. hPanel → Websites → Dashboard next to frogsdream.com.
  2. Left menu: Security → SSL.
  3. The status for frogsdream.com should say Active. If it does not, click Install SSL (or Setup) and choose the free Lifetime SSL. It can take up to 1 hour to become active.

b) Upload and extract the zip

  1. Open Files → File Manager and double-click public_html.
  2. Back up first. Select everything in public_html, choose Compress, make a zip, then right-click that zip and Download it to your computer. Delete the backup zip from the server afterwards. If anything goes wrong, you can put the old files back from it.
  3. Do not touch the lessoncorner folder. The new site has nothing with that name, so extracting the zip will not change anything inside it. The site settings also keep that folder out of Google and out of ads, and stop browsers from caching its files for long.
  4. If you see default.php or index.php directly in public_html (a Hostinger placeholder), right-click it and choose Delete. Only delete it in public_html itself, never inside lessoncorner.
  5. Click the Upload icon (an arrow pointing up) and choose frogsdream-public_html.zip.
  6. When the upload finishes, right-click the zip file and choose Extract. When it asks for a folder, leave it as the current folder (public_html) and confirm. If it asks about existing files, choose to overwrite.
  7. Right-click the zip file again and Delete it. It is not needed on the server.

The zip contains the files directly (no extra folder inside), so after extracting you should see index.html, assets, bingo and so on directly inside public_html. One file, .htaccess, starts with a dot and may be hidden. It is there; it makes the site use https and clean addresses.

Step 4 · about 15 minutes, then a few minutes on 2 or 3 more days

Google Search Console

This tells Google the site exists and shows you which searches bring visitors.

a) Add and verify the site

  1. Go to search.google.com/search-console and sign in with your Google account.
  2. Click the property menu (top left) → Add property. Choose the left box, Domain. Type frogsdream.com (no https, no www). Click Continue.
  3. Google shows a TXT record that starts with google-site-verification=. Click Copy. Leave this tab open.
  4. In a new tab: hPanel → Domains → frogsdream.com → DNS / Nameservers (or DNS Zone Editor).
  5. Under Manage DNS records: Type TXT, Name @, TXT value: paste the Google text, TTL leave as it is. Click Add Record.
  6. Go back to the Google tab and click Verify. If it fails, wait 15 to 60 minutes and click Verify again. DNS changes need time.

b) Submit the sitemap

  1. Left menu: Indexing → Sitemaps.
  2. In Add a new sitemap, type sitemap.xml (Google adds the start of the address for you) and click Submit.
  3. After some hours the status should say Success with about 163 discovered pages.

c) Ask Google to index the most important pages

Google allows only a small number of these requests per day, so do about 6 per day over 3 days.

  1. Paste one address into the search bar at the top (Inspect any URL) and press Enter.
  2. Wait for the result, then click Request indexing. Wait about 1 minute until it confirms.
  3. Repeat for the next address. Tick each one below.

You do not need to request the other pages. Google finds them through the sitemap and the links between pages.

  1. Go to bing.com/webmasters and click Sign in → Google. Use the same Google account as Search Console.
  2. On the welcome screen choose Import your sites from GSC → Import. Allow access, tick frogsdream.com and click Import. Bing also imports your sitemap.
  3. Then open the two links below once each in your browser (click, or copy and paste into the address bar). This is IndexNow: it tells Bing and other search engines about the site right away.

Ping the home page:

https://api.indexnow.org/indexnow?url=https://frogsdream.com/&key=01da6018294bd04f11ce90762863047f

Ping the sitemap:

https://api.indexnow.org/indexnow?url=https://frogsdream.com/sitemap.xml&key=01da6018294bd04f11ce90762863047f

A blank page or a short "OK" message means it worked. Your secret IndexNow key is 01da6018294bd04f11ce90762863047f. The website already contains the matching key file at frogsdream.com/01da6018294bd04f11ce90762863047f.txt; do not delete it.

You can use the same ping link later for any single new or changed page: replace https://frogsdream.com/ after url= with the page address.

Step 6 · about 20 minutes

Sell the Mega Pack (Stripe)

The Mega Pack is a $7 download of ready-made PDFs. It is sold through a Stripe Payment Link with Stripe Managed Payments. With Managed Payments, Stripe's service Link is the seller of record (merchant of record): it takes the payment, charges and pays the sales tax or VAT, checks for fraud, handles disputes and answers buyers' payment questions. You never handle card details.

Your payment link already exists and is built into every website zip: https://buy.stripe.com/6oU5kD4iYeTr5eJ4oN7kc05. You do not need to edit config.js for it. Use the list below to check that its settings are right.

a) Check the payment link settings in Stripe

  1. Stripe Dashboard → Settings → Managed Payments: Managed Payments is on.
  2. Product: name frogsdream Mega Pack, one-time price 7 USD.
  3. Tax code: Digital other news or documents, downloadable, non subscription, with permanent rights.
  4. Tax behavior: tax included in the price (the site says "$7, taxes included").
  5. Payment Links → your link: Let customers adjust quantity is off.
  6. Collect nothing extra: no shipping address, no phone number, no custom fields. Promotion codes are optional.
  7. After payment: choose Don't show confirmation page (redirect your customers) and enter https://frogsdream.com/pack-download-b0b5f94d131b/
  8. Set the support email in your Stripe public business details to hello@frogsdream.com, so Link can reach you about refunds.
  9. Important for "no refunds": in the same public business details, set the Terms of service link to https://frogsdream.com/terms/. Then edit the payment link and switch on Require customers to accept your terms of service. Buyers then tick a box agreeing to the terms, which say they get the files immediately and lose the EU 14-day cancellation right once the download starts. Without that tick, EU law could let a buyer cancel within 14 days even after downloading.

b) Upload the pack to the hidden download folder

  1. File Manager → public_html. Open the folder pack-download-b0b5f94d131b (it arrives with the website zip).
  2. Click Upload and choose deliverables/megapack/frogsdream-Mega-Pack.zip (about 25 MB).
  3. Do not extract it. Buyers download the zip file itself. The folder should now hold index.html and frogsdream-Mega-Pack.zip.
  4. Uploading a new website zip later does not delete this file, because the website zip has no file with that name.

c) Test it once

  1. Open frogsdream.com/premium/ and press Ctrl+F5. The button says "Get the Mega Pack for $7" and opens the Stripe checkout, which shows that the purchase is sold through Link.
  2. Buy it once yourself (you can refund yourself in the Stripe Dashboard). Check that you land on the download page and that the zip downloads and opens.
The data that tells Google the pack is on sale (InStock) is already switched on in the build. If you ever change the price, change it in Stripe and in PACK_PRICE in config.js, and ask Claude to update the $7 text on the site and rebuild. Step 7 · about 4 to 8 weeks after launch · about 15 minutes

Apply to Google AdSense

Wait first. Apply only when Search Console shows 20 or more indexed pages (Search Console → Indexing → Pages → the green "Indexed" number). If you apply too early, Google often rejects new sites for "low value content".
  1. Go to adsense.google.com → Get started. Sign in with your Google account.
  2. Website: frogsdream.com. Country: Poland. Accept the terms.
  3. Fill in your payment address (your real name and home address; this is private and not shown on the site).
  4. Find your publisher ID: AdSense → Account → Settings → Account information. It looks like pub-1234567890123456.
  5. Edit public_html/assets/js/config.js. Put your ID with ca- in front: ADSENSE_CLIENT: "ca-pub-1234567890123456", and save. This adds the AdSense code to every page (except pages that must have no ads).
  6. In AdSense, open Sites → frogsdream.com. For the verification method choose ads.txt snippet. AdSense shows one line of text. Copy it.
  7. Edit public_html/ads.txt. Delete everything in it (the line that starts with #) and paste the line from AdSense. It looks like this (with your own number): 
    google.com, pub-1234567890123456, DIRECT, f08c47fec0942fa0
    Note: in ads.txt the ID starts with pub-, without ca-. Save.
  8. Open frogsdream.com/ads.txt and check that it shows your line.
  9. Back in AdSense, tick that you added the snippet and click Verify, then Request review.

The review takes from a few days up to 2 to 12 weeks. You get an email.

If you are rejected for "low value content": do not worry, this is common. Wait 2 to 4 weeks and request a review again (Sites → frogsdream.com → Request review). You can also ask Claude to expand the pages that have the fewest words.

Step 8 · after approval · about 30 minutes, spread over some weeks

After AdSense approves you

a) Turn on Auto ads, with safe settings

  1. AdSense → Ads → By site. Click the pencil (edit) icon next to frogsdream.com.
  2. Switch Auto ads on.
  3. Under Overlay formats (or Ad formats), turn off: Anchor ads, Vignette ads and Side rail ads. These formats can sit on top of the Generate and Print buttons and cause accidental clicks. Accidental clicks can get an AdSense account limited.
  4. Under Page exclusions → Manage → Add exclusion, add frogsdream.com/bingo-caller/ (people use it on a big screen during games; ads there are not wanted). Choose to exclude the exact page.
  5. Click Apply to site. Ads can take up to an hour to appear.

The website itself already keeps ads away from the tools, and shows no ads on the bingo caller, the embed pages, the Mega Pack page, privacy, terms, contact and the 404 page, and never in print.

b) Block unsuitable ad categories

Teachers and parents use this site, so block adult-ish topics.

  1. AdSense → Brand safety → Content → Blocking controls → All sites.
  2. Open Sensitive categories. Block: Dating, Get Rich Quick, Weight Loss, and Sexual & Reproductive Health.
  3. Open Restricted categories (on the same page, if shown) and block Gambling and betting. (If Gambling is listed under Sensitive categories instead, block it there.)
Do not mark the site as "child-directed" anywhere in AdSense. The site is written for adults (teachers, parents, party hosts). Marking it child-directed would switch it to low-paying ads.

c) Create the European consent message (required)

Visitors from the EU, UK and Switzerland must be asked for consent. Without this message, many ads will not show in Europe. The site does not need any other cookie banner.

  1. AdSense → Privacy & messaging → European regulations → Create message.
  2. Choose site frogsdream.com and language English.
  3. User choices: choose the 3 buttons Consent, Do not consent and Manage options.
  4. Privacy policy URL: https://frogsdream.com/privacy/.
  5. Click Publish.

The "Privacy choices" link in the site footer automatically reopens this message so visitors can change their choice. Test it: open the site in a private window with a European connection, the message should appear.

d) Tax form W-8BEN

  1. AdSense → Payments → Payments info → Manage settings.
  2. Next to United States tax info, click Manage tax info → Add tax info.
  3. Choose Individual and the form W-8BEN. Tax residence country: Poland. Give your Polish tax number (PESEL or NIP) when asked.
  4. Claim the tax treaty benefits for Poland when the form offers it. The form shows the US withholding rate that applies; read it and keep a screenshot for your records.
  5. Sign with your name and submit.

e) Payout to your bank in PLN

  1. AdSense → Payments → Payments info → Add payment method.
  2. Choose Bank transfer (wire). Name as on your bank account, bank SWIFT/BIC (find it in your mBank app; for mBank it is usually BREXPLPWMBK), and your IBAN starting with PL. Use your PLN account.
  3. Save. Within a few days Google sends a small test deposit. Check the amount in your mBank history and type it into AdSense (Payments → Verify).

f) PIN letter

When you earn your first $10, Google posts a letter with a PIN to your home address. This can take 2 to 4 weeks. Enter it under Account → Verification → Address verification (AdSense shows a banner). Payouts start after this, once your balance reaches the payout minimum.

Step 11 · taxes

Taxes in Poland

  • Money from AdSense and from Stripe payouts is taxable income in Poland, also when you use działalność nierejestrowana (unregistered activity).
  • The limit for unregistered activity is 10,813.50 PLN revenue per quarter in 2026 (this is the 2026 figure; it changes each year with the minimum wage). If you go above it, you must register a business within 7 days.
  • Keep a simple income record: date, source (AdSense, Stripe), amount, currency and amount in PLN. A spreadsheet is enough. Save the monthly AdSense payment receipts and Stripe payout reports.
  • Ask the accountant two specific questions: (1) whether you must register for VAT-UE and file VAT-UE summaries because AdSense pays you from Google Ireland, and (2) how to treat Stripe payouts, since Link (a US company) is the seller and you are its supplier.
  • Ask an accountant (księgowy) or your tax office (urząd skarbowy) once how to report this income on your yearly PIT, including foreign currency conversion.

This is general information, not tax advice. Please confirm with an accountant.

This is not a quick money machine. It is a small, honest website that can grow slowly. Please read this so you are not disappointed.

Money: realistic ranges

  • Typical result at month 12: about $20 to $100 per month in total.
  • Real chance of very little: about a 30 to 40% chance it earns under $10 per month in the first year. Most new niche sites (about 73%) stay under 1,000 visits per month in year one.
  • Good case: several hundred dollars per month, most likely in the second Halloween and Christmas season (Oct to Dec 2027) and after.
  • Ads: about $3 to $6 per 1,000 page views from the US, UK, Canada and Australia. Less from other countries. At low traffic this is small money.
  • Mega Pack: we guess about 1 to 3 buyers per 1,000 visitors. This is a guess, not measured. It could be lower.

Risks you should know

  • AdSense approval is not guaranteed. Rejections for "low value content" are common for new sites. Just wait and reapply.
  • Some pages may not be indexed. Google may index only part of the roughly 160 pages at first. That is normal for a new site.
  • Accidental clicks. Never click your own ads, and never ask friends to click them. This is the fastest way to lose an AdSense account.
  • Stripe Managed Payments is a newer Stripe service. If its rules or fees change, read Stripe's email and ask Claude for help. The site only needs a new PACK_URL to switch to another seller.
  • Competition. Big printable sites already exist. This site wins only on many small specific searches, good quality (Letter and A4, UK 90-ball tickets, answer keys, ink saver) and seasonal pages.
  • The research behind these numbers is limited. Many traffic tools were blocked during research, so the numbers come from public summaries, not exact data. Your own Search Console data after 3 to 6 months is the real guide.
  • Honesty. The site says openly that it was made with AI assistance. There are no fake reviews or ratings. Please keep it that way; it protects you from Google and AdSense penalties.

Your time

About 1.5 to 2 hours of one-time setup (steps 1 to 8, spread over some weeks), then about 5 minutes per month. Nothing on the site goes out of date by itself: there are no dates, prices of other companies or news on it.

  • Do not add other trackers, analytics or cookie tools. The privacy page says the site uses none apart from Google's ads and consent tools.
