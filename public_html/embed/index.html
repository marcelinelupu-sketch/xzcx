Embed Our Free Tools on Your Site

If you run a teaching blog, a class page, a library site or a party planning site, you can put a working frogsdream generator right on your own page. Your readers make and print their sheets without leaving your site, and it costs nothing.

How to embed a tool

  1. Copy the code for the tool you want from the boxes below.
  2. In your website editor, add an HTML, Custom HTML or Embed block where you want the tool to appear. In WordPress this is the Custom HTML block; Google Sites uses Insert, then Embed, then Embed code.
  3. Paste the code and publish the page.

The tool fills the width of your content column. If it looks cramped, raise the height number in the code. You can also press Embed this tool under any generator on this site to copy the same code.

A few simple rules

  • Keep the credit link. The short link under the iframe is the only thing we ask in return. Please leave it visible and don't add nofollow to it.
  • No ads inside the tool. The embedded versions show no advertising, so your page stays clean. Ads on the rest of your own page are up to you.
  • Don't pass it off as your own. You're welcome to write about the tool and recommend it, but please don't present it as something you built or sell access to it.
  • Free for everyone. Your readers can use the embedded tool and print the results under the same free terms as this site.

Privacy for your readers

The embedded tool runs in your reader's browser. The words they type are not sent to us. Like any web page, loading the iframe means our host receives a normal server request, and the tool may save the reader's last list in their own browser so it is still there next time. Our privacy policy explains both. If your site needs to list third-party content in its own privacy notice, you can name frogsdream (frogsdream.com) as an embedded tool.

FAQ

Does embedding cost anything?

No. Embedding is free for personal, school, library and non-commercial sites, and for blogs that carry their own ads.

Can my readers print and download PDFs from the embedded version?

Yes. Print, Download PDF and Generate all work inside the embed. A share link copied from inside the embed opens the full tool here on frogsdream.com with the same words.

Can I embed the scavenger hunt generator, charts or bingo caller?

Not yet. For now the bingo card generator, word search maker and word scramble maker have embed versions. You can still link to the other tools from your page.
